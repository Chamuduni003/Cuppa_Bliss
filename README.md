# ☕ Cuppa Bliss - Coffee Shop Management System

A desktop-based management system designed to streamline daily operations and administrative workflows for a coffee shop. Built with Java and structured using Object-Oriented Programming (OOP) principles and the MVC architectural pattern.

---

## 🌟 Key Features

* **Menu Management**: Add, update, and manage coffee items, beverages, and pricing dynamically.
* **Order & Billing Processing**: Handle customer orders, calculate totals, and generate transactions efficiently.
* **Database Integration**: Secure and reliable data storage using MySQL for menu data, sales, and order records.
* **Administrative Interface**: Intuitive UI designed to enhance operational efficiency for cashiers and managers.

---

## 🛠️ Tech Stack & Architecture

* **Language**: Java (JDK 8 / 11+)
* **IDE**: NetBeans IDE
* **Architecture**: MVC (Model-View-Controller) Pattern
* **Database**: MySQL
* **GUI Framework**: Java Swing / AWT

---

## 🏗️ Software Architecture (MVC)

* **Model**: Handles data management, database interactions, and business logic.
* **View**: Provides the graphical user interface (GUI) for cashiers and administrators.
* **Controller**: Processes user inputs, coordinates between Model and View, and handles operations.
